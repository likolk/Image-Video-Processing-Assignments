# Image and Video Processing assignments

My solutions to the four assignments of the Image and Video Processing course at Università della Svizzera italiana (USI), spring 2023. Written in MATLAB, each with a PDF report.

| Folder | Topics |
| --- | --- |
| `DIP_ASSIGNMENT_1/` | Point operations, histograms, histogram equalisation, white balance, matting |
| `DIP_hw2/` | Colour handling, Gaussian and anisotropic filtering, image stylisation |
| `hw3/` | Assignment 3, with the task sheet and my report |
| `IVP_Assignment_4/` | Assignment 4, with the task sheet and my report |

Each folder holds the `.m` scripts, the input images and my report (`Likollari_Kelvin_*.pdf`).

These are coursework solutions and not every answer is correct. Use them as a reference, not as a source of truth.
